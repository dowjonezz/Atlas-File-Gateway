Поддерживаются любые типы файлов. Максимальный размер по умолчанию — 10 МБ.

API для агентов

GET /api/list, /api/read, /api/write, /api/chunk и /api/finish. Для скриптов используй заголовок X-API-Key. Токен задаётся отдельно от пароля Web UI.
